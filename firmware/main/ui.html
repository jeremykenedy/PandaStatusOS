Features
Everything here is off out of the box, and the device behaves like the factory one until a switch is on. Each switch is stored on the device.
Brightness per state
One brightness for idle, one for printing and one for error, instead of one for all three.
Effect per state
Each of idle, printing and error runs its own animation instead of a solid colour, in the state's colour.
Effect colours
Each effect gets its own colours, one lit and one unlit, each for printing and for otherwise, instead of the state colour above.
Brightness, speed and direction per effect
Each effect carries its own brightness, speed and direction, as one setting, instead of the sliders above.
Brightness ramp
The brightness sweeps each cycle from the effect's own value to a second one, then starts over.
Progress bar
The bar fills with the print's progress. Chosen as a state's effect.
Progress, animated
The progress bar with a chase running over it and a breathing tip, so a print in progress reads as one from across the room.
Barber pole
A two-colour pole crawling through the progress bar; the band width is adjustable.
Progress colour ramp
The whole bar one colour, sliding from the unlit colour to the lit colour across the print.
Temperature gradient
The whole bar one colour between the unlit colour at the cold end and the lit colour at the hot end, following one temperature from the printer.
Hot warning
While a temperature is at or past a threshold, the bar pulses a colour over whatever it is showing, in both modes.
Error flash
While the printer reports an error, the bar flashes a colour over whatever it is showing, in both modes; colour, brightness and rate are adjustable.
Live preview
Pin the bar to a chosen state for half a minute, to see a setting without running a print. The layers and the effects that read the print follow the pinned state.
Named effects
An editor for effects: the effect, its colours as stops, timing and direction, saved under a name and used for any state. Adds two palette effects that lay the colours across the bar.
Effects per stage
Each of the display's fifteen stages gets its own named effect; a stage without one inherits its state's effect.
Settings as a file
Export every setting as one JSON file and import it back; the three passwords stay out of it.
Restart button
A button on this page that restarts the device now, keeping every setting. The factory's own restart command is named reset; this one is named what it does.
Find the printer again
When the bound printer takes a new address and stops answering, the device looks for it by serial number and binds again. The search itself finds nothing yet: it has no documented mechanism.
Fault codes on the bar
When the device cannot reach the network or the printer, the bar blinks a colour for the area and a count for the reason, instead of what it usually shows. The table is in the troubleshooting help.
Settings as a file
The file names your network and your printer and holds every setting except the Wi-Fi, hotspot and access-code passwords; keep it private. Importing applies the whole file or none of it.
The three resets
Reset lighting
Puts brightness, speed and the three state colours back to their defaults. Nothing else. The button is on the Lighting page.
Go to Lighting
Restart
The device restarts itself after a hostname or hotspot address change, and after a firmware update. There is no restart button.
With the switch on, the button restarts the device now. Nothing is erased.
Factory reset
Erases every setting the device holds: Wi-Fi, hotspot, printer binding, hostname, language, lighting. The device restarts as new. There is no undo.
