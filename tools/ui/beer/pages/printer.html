Bind to a printer
This device finds Bambu printers on the same network. Pick yours and it fills in the serial; the access code is on the printer's own screen.
Bind a vent
This device finds vents running our firmware on the same network. Pick yours, or type its address.
  • State
Both devices show the same six digits. Check that they match, then confirm on each.
Pairing code
Each of these copies once, when you press it. Nothing follows afterwards: press again to copy again.
